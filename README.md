# Library

A full-stack ecommerce book store where users can browse books and add them to their cart for checkout.

## Technologies
- React
- JavaScript
- CSS
- FontAwesome

## Features
- Responsive design
- Dynamic Data Representation
- Interactive checkout

## Future Improvements
- Connect Stripe for payment processing.
- Implement user access to book file after purchasing

## Author
Developed by Broady Butler

## Getting Started

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

1. Clone Repository

- git clone https://github.com/broadaciousb/libraryReact

2. Install Dependencies

- npm install

3. Run Development Server

- npm start

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
